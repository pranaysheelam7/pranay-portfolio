- style.css

- assets/proof/*.png

## How to host on GitHub Pages
1. Create a new GitHub repository (for example: pranay-portfolio).
2. Upload all files and folders from this package to the repository root.
3. Go to Settings > Pages.
4. Under Source, choose `Deploy from a branch`.
5. Select branch `main` and folder `/ (root)`.
6. Save. Your site will be live in a minute.

## How to update resume later
Replace:
assets/resume/pranay-resume.pdf

Keep the same filename to avoid changing code.

## How to update proof screenshots
Replace the files inside:
assets/proof/
with the same filenames if you want to keep the current layout.
